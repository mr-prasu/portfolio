# Prasnna Kumar — Personal Portfolio

## Project Overview

This project is a responsive personal portfolio website for **Prasanna Kumar**, an aspiring Data Scientist and Applied AI learner. It introduces the profile, technical skills, learning journey, focus areas, featured projects, and contact links in a clean one-page layout.

The site highlights interests in Python, data analysis, machine learning, generative AI, agentic AI, natural language processing, and AI automation. It also links to featured work, including a Python Programming Quiz and the NeuroScan AI post-COVID brain alteration detection project.

## Features

- Fixed navigation with smooth scrolling to each page section
- Hero profile section with social, GitHub, LinkedIn, and email links
- About section with professional introduction
- Technical-skills cards
- Featured-project cards with external project links
- Learning-journey timeline-style content
- Contact call-to-action
- Responsive layout for smaller screens
- Header shadow effect when the page is scrolled

## Technologies Used

- **HTML5** — page structure and content
- **CSS3** — styling, responsive layout, hover effects, and theme
- **JavaScript** — smooth navigation and scroll-based header effect
- **Font Awesome** — social-media and email icons (loaded from CDN)
- **Google Fonts** — Poppins typeface (loaded from CDN)

## Run Locally

No build process or server is required.

1. Download or clone this project.
2. Open `index.html` in any modern web browser.

For the best experience, use a local development server. For example, with Python installed:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Customization

Update `index.html` to change the profile content, skills, projects, links, or contact details. Replace images in the `photo/` folder and update the corresponding image paths in the HTML. Colors, typography, layout, and responsive behavior can be adjusted in `style.css`.
